# Coding Standards Reference

**Read this file when writing code or reviewing PRs.**

## Quick Rules
- **TypeScript**: Strict types, no `any`
- **React**: Functional components, named exports, props interface
- **Backend**: Input validation (Zod), centralized error handling
- **Styling**: TailwindCSS only (no inline styles)
- **Imports**: Use aliases (@/, @codeinsight/)
- **Commits**: Conventional (feat:, fix:, refactor:, etc.)

See full standards in this file for component patterns, testing, performance targets.
