## 🎯 사용 방법

### 1. 패턴 찾기
```bash
# 특정 패턴 검색
grep -r "캐싱" golden_samples/

# 카테고리별 탐색 (실제 프로젝트는 packages/frontend/)
ls golden_samples/frontend/hooks/
```

### 2. 패턴 적용
각 파일은 다음 구조를 따릅니다:
- **의도 (Why)**: 왜 이 패턴이 필요한가?
- **문제 상황 (Problem)**: 이 패턴 없이 발생하는 문제
- **해결책 (Solution)**: 핵심 코드 + 설명
- **적용 사례 (Usage)**: 실제 사용 예시
- **주의사항 (Caveats)**: 잘못 사용하면 생기는 문제

### 3. 새 패턴 추가
1. 해당 카테고리 디렉토리에 파일 생성
2. 템플릿 구조 준수
3. 실제 동작하는 코드만 포함
4. 테스트 가능한 코드로 작성

## ✅ 품질 기준

골든 샘플로 선정되려면 다음을 만족해야 합니다:

- [ ] **테스트 가능**: 독립적으로 테스트 가능
- [ ] **단일 책임**: 하나의 명확한 목적
- [ ] **재사용성**: 다른 프로젝트에도 적용 가능
- [ ] **문서화**: 주석 + 사용 예시 포함
- [ ] **실전 검증**: 실제 프로덕션 환경에서 검증됨
