## LlamaGen.AI (1순위 추천)

### 기본 정보
| 항목 | 내용 |
|------|------|
| **URL** | https://llamagen.ai |
| **무료 사용** | ✅ 가입 없이 바로 가능 |
| **해상도** | 4K Ultra-HD |
| **캐릭터 일관성** | ✅ IP 데이터베이스로 유지 |
| **스토리보드** | 한 세션에 최대 64장 |
| **언어** | 50개국어 지원 |

### 주요 기능
- **Text-to-Comic**: 텍스트 스토리를 만화로 자동 변환
- **4K 해상도**: Ultra-HD 품질 출력
- **캐릭터 일관성**: 시리즈 전체에서 캐릭터 외형 유지
- **멀티모달**: 만화, 비주얼 노벨, 영화 스타일 영상까지 생성 가능
- **AI 챗 어시스턴트**: 생성된 만화 이해/요약 도움

### 사용 방법
1. https://llamagen.ai 접속
2. "Launch app" 또는 "Get started for free" 클릭
3. 스토리/프롬프트 입력
4. AI가 자동으로 패널, 캐릭터, 스타일 생성

## Anifusion (망가 전문)

### 기본 정보
| 항목 | 내용 |
|------|------|
| **URL** | https://anifusion.ai |
| **무료 티어** | 월간 제한 크레딧 |
| **워터마크** | ❌ 없음 (무료에서도) |
| **상업용** | ✅ 허용 (약관 확인 필요) |

### 무료로 가능한 것
- 무제한 캔버스 및 스케치 도구
- 캐릭터 시트 생성 (제한적)
- 패널 레이아웃 템플릿
- 텍스트 및 말풍선 도구
- 고해상도 다운로드

### 무료 티어 한계
- 월간 생성 쿼터 (매월 리셋)
- LoRA 트레이닝 크레딧 제한
- 유료보다 적은 모델 선택
- 우선 처리 없음

### 무료로 만들 수 있는 양
- 월 5-10페이지 단편 만화
- 캐릭터 디자인 시트
- 커버 아트 및 홍보 일러스트
- 스토리보드 및 컨셉 아트

## HuggingFace Space 연동 이슈

### 문제점
- `hf.space` 도메인 접근 불가 (WSL2 & Windows 모두)
- DNS는 해석되나 연결 타임아웃

### 시도한 해결책
- `/api/whoami` → `/api/whoami-v2` 변경
- 환경변수 `HF_TOKEN` 설정

### 필요한 해결책
- VPN 사용
- 또는 다른 만화 AI 서비스 사용 (LlamaGen 등)
