# Professor Outreach Email Templates

## English Template (US Professors)

**Subject:** Free code execution visualizer for [Course Name] — would love your feedback

---

Hi Professor [Name],

I built a free, open-source tool that visualizes code execution step by step — and I think it could help students in your [Course Name] class at [University]. I know you're busy, so I'll keep this short.

**What it does:** Students step through code line by line and watch memory, variables, and call stacks update in real time.

- C: Stack, Heap, BSS, DATA, TEXT segment layout with pointer visualization
- Python: Variable tracking with scope visualization
- JavaScript: Event loop, scope chain, prototype chain, Promise flow
- Java: JVM memory model with object references

**Two modes:** Lesson mode (guided curriculum) and Playground mode (students write their own code and see it visualized).

Live demo: https://codeinsight.online
GitHub: https://github.com/jammy0903/CodeInsight

It's completely free and MIT licensed. If you have a minute to check it out, I'd really appreciate any feedback — what's missing, what would make it actually useful in a classroom setting.

Thank you for taking the time to read this. I know how packed your schedule must be.

Best,
[Your Name]

## Outreach Strategy

### Core Rule: One Professor, One Personalized Email
- Every email must be individually written and sent one at a time
- Reference the professor's specific course (e.g. "I saw you teach CS61A")
- Mention their university by name
- If they've published CS education work, reference it briefly
- Never batch send, never BCC, never copy-paste the same email to multiple people

### Personalization Checklist (per email)
1. Professor's name
2. University name
3. Specific course they teach (from CSV list)
4. Language relevance (e.g. if they teach C, highlight the memory visualization)
5. Optional: mention a specific pain point their students likely face

### Sending Pace
- Max 10-15 emails per day (quality over quantity)
- Best time: Tuesday-Thursday, 9-11 AM in the professor's local time zone
- Space them out — don't send all at once
- Follow up once after 1 week if no response, then stop

### Do NOT
- Mass BCC or CC anyone
- Send identical copy-paste emails
- Use aggressive sales language
- Follow up more than once
- Send more than 15 in a single day
