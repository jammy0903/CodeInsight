## 🔴 예상 질문 1: "6개월만 비교한 거 아닌가? 장기적으로는 On-premise가 더 싸지 않나?"

### 핵심 답변
"좋은 질문입니다. 장기 TCO를 분석해봤습니다."

### 데이터 근거

**손익분기점 분석** (출처: Swfte AI TCO Analysis 2026, Lenovo TCO Study)

| GPU 구성 | 초기 비용 | 손익분기점 |
|----------|----------|------------|
| 8x L40S | $79,000 | **800M 토큰/월** |
| 16x A100 | $232,000 | **2.5B 토큰/월** |
| 8x H100 | $335,000 | **3.5B 토큰/월** |

**I&C 예상 사용량**: 30명 × 100M = **100M 토큰/월**

→ 손익분기점(800M)의 **1/8 수준**
→ **Cloud가 압도적으로 유리한 구간**

### 추가 논거
- "대규모 사용(10B+ 토큰/월)에서는 On-premise가 57% 저렴합니다"
- "하지만 우리 규모(100M 토큰/월)에서는 Cloud가 5-8배 저렴합니다"
- "사용량이 10배 늘어도(1B 토큰/월) 아직 손익분기점에 못 미칩니다"

### 출처
- Swfte AI: https://www.swfte.com/blog/cloud-vs-onprem-ai-tco-analysis
- Lenovo: https://lenovopress.lenovo.com/lp2225

## 🔴 예상 질문 2: "Private VPC가 정말 On-premise 수준의 보안인가?"

### 핵심 답변
"AWS Bedrock은 엔터프라이즈급 보안 인증을 모두 획득했습니다."

### 데이터 근거 (AWS 공식)

| 인증 | 상태 | 의미 |
|------|------|------|
| **SOC 1, 2, 3** | ✅ 완료 | 재무/운영 통제 감사 통과 |
| **ISO 27001** | ✅ 완료 | 국제 정보보안 표준 |
| **HIPAA** | ✅ Eligible | 의료 데이터 처리 가능 |
| **GDPR** | ✅ 준수 | EU 개인정보보호 준수 |
| **CSA STAR Level 2** | ✅ 완료 | 클라우드 보안 표준 |

### Private Endpoint 구조
```
[개발자 PC] → [VPC 내부] → [Private Endpoint] → [Bedrock]
                 ↑
          인터넷 경유 없음
```

### 핵심 포인트
1. **데이터 학습 미사용 보장**: AWS 계약상 고객 데이터로 모델 학습하지 않음
2. **CloudTrail 감사**: 모든 API 호출 로그 기록
3. **IAM 권한 제어**: 사용자별 세밀한 접근 통제

### 출처
- AWS 공식: https://aws.amazon.com/bedrock/security-compliance/
- AWS FAQ: https://aws.amazon.com/bedrock/faqs/

## 🔴 예상 질문 4: "100M 토큰/월 예상이 현실적인가?"

### 핵심 답변
"Claude Code 공식 문서와 실제 사례를 기반으로 산정했습니다."

### 데이터 근거 (Claude Code 공식)

| 지표 | 수치 | 출처 |
|------|------|------|
| 평균 비용 | **$100-200/개발자/월** | Claude Code 공식 문서 |
| 일일 비용 | **평균 $6/일** | Claude Code 공식 |
| 90% 사용자 | **$12/일 미만** | Claude Code 공식 |

### 계산 검증
```
제안서: 100M 토큰/월 × $0.012 = $1,200 ≈ ₩1,560,000

공식 기준: 30명 × $100~200 = $3,000~6,000 ≈ ₩390~780만원
```

### 솔직한 인정 (필요시)
"공식 문서 기준으로는 **월 400~800만원**이 더 현실적일 수 있습니다.
하지만 이는 풀타임 사용 기준이며, 실제 업무 중 AI 사용 비율을 고려하면
**월 150~300만원** 수준으로 예상됩니다."

### 출처
- Claude Code 공식: https://code.claude.com/docs/en/costs

## 🟠 예상 질문 5: "왜 재무팀은 ChatGPT를 쓰게 하나? 보안 문제 아닌가?"

### 핵심 답변
"개발 코드와 비개발 문서는 보안 민감도가 다릅니다."

### 논리 구조

| 구분 | 내용 | 유출 시 피해 |
|------|------|-------------|
| **개발 코드** | 핵심 알고리즘, 로직, API | 🔴 치명적 (경쟁력 상실) |
| **일반 문서** | 보고서, PPT, 회의록 | 🟡 제한적 (공개 정보 기반) |

### 통제 방안
1. **사용 정책 문서화**: "코드/로직 입력 금지" 명문화
2. **교육 필수화**: 온보딩 시 보안 교육
3. **주기적 감사**: 분기별 사용 로그 점검

### 대안 (질문이 계속되면)
"만약 우려가 크시다면, 재무팀도 AWS Bedrock으로 통일할 수 있습니다.
다만 비용이 월 25만원 → 60만원으로 증가합니다."

## 🟠 예상 질문 6: "실패하면 900만원만 손해? 인건비는?"

### 핵심 답변
"파일럿 실패 시 총 비용을 다시 계산해드리겠습니다."

### 현실적 비용 계산

| 항목 | 비용 | 비고 |
|------|------|------|
| API 비용 | 900만원 | 6개월 |
| 인프라 설정 | 100만원 | 일회성 |

### 비교 논거
```
제안 실패 시: 1,750만원 손실
기존 계획 실패 시: 1.7억원 손실 (10배 차이)
```

### 핵심 메시지
"실패 비용을 과소평가한 점은 인정합니다.
하지만 **1,750만원 vs 1.7억원**으로 비교해도
리스크 차이는 **10배**입니다."
