## 📊 보충 슬라이드 6: Exit Strategy (실패 대응)

### 제목
**"실패해도 손실을 최소화하는 Exit Strategy"**

### 월별 체크포인트

| 시점 | 체크 항목 | Exit 기준 |
|------|----------|-----------|
| **1개월** | 환경 구축 완료 | 기술적 장애 발생 시 |
| **2개월** | 파일럿 5명 사용률 | 사용률 10% 미만 |
| **3개월** | 생산성 개선 측정 | 개선 효과 10% 미만 |
| **4개월** | 전체 확대 판단 | 만족도 50% 미만 |
| **6개월** | 최종 ROI 평가 | 목표 미달성 |

### 단계별 손실 비용

```
1개월 Exit: ₩200만원 손실
2개월 Exit: ₩400만원 손실
3개월 Exit: ₩600만원 손실
6개월 Exit: ₩1,700만원 손실 (최대)

vs 기존 계획: ₩1.7억원 손실 (10배)
```

### Exit 시 회수 가능 자산
- LangChain 연동 코드 → 다른 프로젝트 활용 가능
- 보안 아키텍처 설계 → 향후 AI 도입 시 재사용
- 팀 AI 역량 → 무형 자산
