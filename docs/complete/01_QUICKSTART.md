# Quick Start Guide

## Prerequisites
- Node.js 18+
- Python 3.10+

## Installation
```bash
# Frontend
cd frontend && npm install

# Backend Node
cd backend-node && npm install

# Backend Python
cd backend && pip install -r requirements.txt
```

## Running
```bash
./start-dev.sh
```

## Stopping
```bash
./stop-dev.sh
```
