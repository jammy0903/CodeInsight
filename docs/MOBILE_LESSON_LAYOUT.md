## 7. 핵심 원칙

1. **데스크톱 유지** - 기존 탭 구조 그대로
2. **모바일 AI = 오버레이** - FAB → 전체화면 모달
3. **설명 접기** - 모바일에서 기본 접힘
4. **터치 최적화** - 48px 이상 터치 영역
5. **성능 우선** - 불필요한 리렌더 방지
