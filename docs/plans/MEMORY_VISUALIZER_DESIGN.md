## 📋 핵심 개념 (중요!)

### 변수 ≠ 메모리

```c
int x = 10;
int *p = &x;
```

**잘못된 이해:**
```
메모리:  [x] [p]        ← 변수가 메모리에 저장됨 (❌ 틀림)
```

**정확한 개념:**
```
메모리주소     메모리에 저장된 값
0x1000   →    [10]              ← 실제 저장되는 것
0x1004   →    [0x1000]          ← 실제 저장되는 것

변수는?
- "x" = 0x1000 주소의 값을 참조하는 "별칭(alias)"
- "p" = 0x1004 주소의 값을 참조하는 "별칭(alias)"
```

**핵심:**
✅ 메모리에 저장되는 것 = **값만**
✅ 변수 = **값을 참조하는 이름**
✅ 포인터 = **다른 주소를 값으로 갖는 변수**

## 🎨 시각화 디자인 (분리형)

### 레이아웃 구조

```
┌─────────────────────────────────────────────────────┐
│ 변수 영역 (메모리 아님 - 단순 별칭/참조)            │
├─────────────────────────────────────────────────────┤
│ x (🟦 파란색)                                       │
│ p (🟥 빨간색)                                       │
│  │                                                  │
│  └─ 이 선들이 "참조"를 의미 (데이터 플로우)        │
│
├─────────────────────────────────────────────────────┤
│ 메모리 영역 (실제 값이 저장되는 곳)                │
├─────────────────────────────────────────────────────┤
│                                                     │
│ Stack                                              │
│ ┌──────────────────────────┐                       │
│ │ [0x1000] 🟦 10           │ ← x가 여기 참조     │
│ │ [0x1004] 🟥 0x1000       │ ← p가 여기 참조     │
│ │          (0x1000을 가리킴) │                     │
│ └──────────────────────────┘                       │
│                                                     │
│ Heap                                               │
│ ┌──────────────────────────┐                       │
│ │ [0x8000] malloc: ...     │                       │
│ └──────────────────────────┘                       │
│                                                     │
└─────────────────────────────────────────────────────┘
```

### 색상 매칭으로 연결 관계 표현

```
변수명      메모리 값
──────────────────────
x (🟦) ─→ [0x1000] 🟦 10
           ↓ 이 값이 10

p (🟥) ─→ [0x1004] 🟥 0x1000
           ↓ 이 값이 0x1000을 가리킴
           (0x1000에 가는 포인터)
```

## 🏗️ 컴포넌트 구조

```
MemoryVisualizer
├── VariablesPanel (상단)
│   ├── VariableTag (x, p, ...)
│   │   - 변수명
│   │   - 색상 (포인터면 다른 색)
│   │   - 변경 표시 (노란색 강조)
│   │   - 선 시작점 (데이터 플로우)
│   │
│   └── 참고: "이들은 메모리에 없고, 단순히 값을 참조합니다"
│
├── MemoryPanel (하단)
│   ├── StackSection
│   │   └── MemoryBlock
│   │       - 주소 ([0x1000])
│   │       - 값 (10)
│   │       - 값 강조 (이게 실제 메모리에 저장됨!)
│   │       - 선 끝점
│   │
│   └── HeapSection
│       └── MemoryBlock (위와 동일)
│
└── PointerLines (오버레이)
    └── VariableTag → MemoryBlock
        - 색상으로 어떤 변수와 연결되는지 표현
        - 선이 "참조"를 의미
```

## 🎯 주요 표현 포인트

### 1. 값 강조
```
┌─────────────────────┐
│ [0x1000]    10      │
│             ^^^^^^  │
│             강조됨!  │
│          (실제 저장됨)│
└─────────────────────┘
```

### 2. 포인터 값도 "값"
```
┌─────────────────────┐
│ [0x1004]  0x1000    │
│           ^^^^^^^   │
│           강조됨!    │
│        (포인터도 값) │
│     (0x1000을 가리킴)│
└─────────────────────┘
```

### 3. 변수는 메모리 외부
```
변수명  →  메모리 주소의 값을 "참조"
(메모리에 안 저장됨)
```

### 4. 변경 추적
```
변수 x가 변경됨:
┌──────────────────────────┐
│ x (🟦) [변경됨]          │
│                          │
│ [0x1000] 10 → 20         │ (값이 변경됨!)
│          ^^^    ^^       │
│          이전   새로운    │
└──────────────────────────┘
```

## 📐 디자인 사양

### 색상 체계
| 용도 | 색상 | 사용 |
|------|------|------|
| Stack | Blue (#3b82f6) | 메모리 블록, 변수명 |
| Heap | Green (#10b981) | 메모리 블록, 변수명 |
| Pointer | Orange (#f97316) | 포인터 화살표, 연결선 |
| Changed | Yellow (#fbbf24) | 변경된 값 강조 |
| Text | Gray (#6b7280) | 주소, 설명 |

### 레이아웃 비율
```
변수 패널: 20% (상단)
메모리 패널: 75% (중단)
패딩: 5%
```

### 애니메이션
- ✅ 값 변경: 노란색 펄스 (0.5초)
- ✅ 변수 추가: 슬라이드 인 (0.3초)
- ✅ 포인터 선: 페이드 인 (0.4초)
- ✅ 메모리 블록: 높이/배경 애니메이션
