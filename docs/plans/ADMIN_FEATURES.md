## 🛠 기술 스택 (구현 시 필요)

### Frontend
- 모달: `@headlessui/react` 또는 shadcn Dialog
- 테이블: `@tanstack/react-table` (정렬, 필터)
- 차트: `recharts` (통계 그래프)
- Drag & Drop: `@dnd-kit/core`
- 검색: Debounced input
- CSV Export: `papaparse`

### Backend
- 이메일: `nodemailer`
- 일괄 작업: `bullmq` (작업 큐)
- 로그: `winston` (이미 사용 중)
- 스케줄: `node-cron` (자동 리포트)
- 백업: `pg_dump` (PostgreSQL)
