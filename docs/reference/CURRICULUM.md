## Phase 1: C 언어 (MVP)

### Lesson 1: 변수와 메모리 주소

**핵심 개념**
```
변수 = 메모리에 이름 붙인 공간
```

**코드**
```c
int a = 10;
int b = 20;
```

**시각화**
```
Stack:
┌────────────┐
│ a: 10      │ 0x1000
│ b: 20      │ 0x1004
└────────────┘
```

**퀴즈**
> Q: `a`와 `b`의 주소 차이는?
> - 1바이트
> - 4바이트 ✓
> - 8바이트

**착각 포인트**
> "많은 사람들이 변수 이름이 메모리에 저장된다고 생각합니다.
> 실제로는 값만 저장되고, 이름은 컴파일러만 알아요."

---

### Lesson 2: 포인터는 값이다

**핵심 개념**
```
포인터 = 주소를 저장하는 변수
```

**코드**
```c
int a = 10;
int *p = &a;
```

**시각화**
```
Stack:
┌────────────┐
│ a: 10      │ 0x1000
│ p: 0x1000 ─┼──┐
└────────────┘  │
                ↓
```

**퀴즈**
> Q: `p`에 저장된 값은?
> - 10
> - 0x1000 ✓
> - a

**착각 포인트**
> "포인터가 특별한 무언가라고 생각하지 마세요.
> 그냥 주소를 담는 평범한 변수입니다."

---

### Lesson 3: 포인터 역참조

**핵심 개념**
```
*p = "p가 가리키는 곳의 값"
```

**코드**
```c
int a = 10;
int *p = &a;
*p = 20;
```

**시각화 (Step 3)**
```
Stack:
┌────────────┐
│ a: 20      │ ← *p = 20 으로 변경됨
│ p: 0x1000 ─┼──┘
└────────────┘
```

**퀴즈**
> Q: 마지막 줄 실행 후 `a`의 값은?
> - 10
> - 20 ✓
> - 0x1000

---

### Lesson 4: 배열과 포인터

**핵심 개념**
```
배열 이름 = 첫 번째 원소의 주소
arr[i] == *(arr + i)
```

**코드**
```c
int arr[3] = {1, 2, 3};
int *p = arr;
```

**시각화**
```
Stack:
┌────────────┐
│ arr[0]: 1  │ 0x1000 ← arr, p
│ arr[1]: 2  │ 0x1004
│ arr[2]: 3  │ 0x1008
└────────────┘
```

**퀴즈**
> Q: `*(arr + 1)`의 값은?
> - 1
> - 2 ✓
> - 0x1004

---

### Lesson 5: 함수와 값 전달

**핵심 개념**
```
C는 항상 "값"을 복사해서 전달
```

**코드**
```c
void change(int x) {
    x = 100;
}

int main() {
    int a = 10;
    change(a);
    // a는 여전히 10
}
```

**시각화**
```
main의 Stack:        change의 Stack:
┌────────────┐       ┌────────────┐
│ a: 10      │       │ x: 100     │ ← 복사본
└────────────┘       └────────────┘
```

**퀴즈**
> Q: `change(a)` 호출 후 `a`의 값은?
> - 10 ✓
> - 100
> - 에러

**착각 포인트**
> "함수에 변수를 넘기면 원본이 바뀐다고 생각하는 분이 많아요.
> C에서는 항상 '복사본'이 전달됩니다."

---

### Lesson 6: 함수와 포인터 전달

**핵심 개념**
```
원본을 바꾸려면 주소를 전달
```

**코드**
```c
void change(int *p) {
    *p = 100;
}

int main() {
    int a = 10;
    change(&a);
    // a가 100으로 변경됨
}
```

**시각화**
```
main의 Stack:        change의 Stack:
┌────────────┐       ┌────────────┐
│ a: 100     │ ←─────┤ p: 0x1000 ─┼──┘
└────────────┘       └────────────┘
```

**한 줄 수정 미션**
> Day 5의 코드에서 딱 한 줄만 바꿔서 `a`가 변경되게 하세요.

### Lesson 7: Stack vs Heap

**핵심 개념**
```
Stack = 자동 관리 (함수 끝나면 사라짐)
Heap = 수동 관리 (직접 free 해야 함)
```

**코드**
```c
void foo() {
    int a = 10;           // Stack
    int *p = malloc(4);   // Heap
    *p = 20;
}  // a는 사라짐, *p는 남아있음!
```

**시각화**
```
Stack:              Heap:
┌────────────┐      ┌────────────┐
│ a: 10      │      │ 20         │ ← malloc
│ p: 0x2000 ─┼──────┼────────────┘
└────────────┘
```

**퀴즈**
> Q: 함수가 끝난 후 Heap의 20은?
> - 사라진다
> - 남아있다 ✓ (메모리 누수!)
> - 에러

---

### Lesson 8: 동적 메모리 할당

**핵심 개념**
```
malloc = 메모리 빌리기
free = 메모리 돌려주기
```

**코드**
```c
int *p = malloc(sizeof(int));
*p = 100;
free(p);
// p는 여전히 0x2000을 가리킴 (Dangling Pointer!)
```

**착각 포인트**
> "`free(p)` 하면 p가 NULL이 된다고 생각하는 분이 있어요.
> p는 여전히 이전 주소를 가리킵니다. 위험해요!"

**한 줄 수정 미션**
> `free(p)` 다음에 한 줄 추가해서 안전하게 만드세요.
> 정답: `p = NULL;`

### Lesson 9: 이중 포인터

**핵심 개념**
```
int **pp = "포인터를 가리키는 포인터"
```

**코드**
```c
int a = 10;
int *p = &a;
int **pp = &p;
```

**시각화**
```
Stack:
┌────────────┐
│ a: 10      │ 0x1000
│ p: 0x1000 ─┼──┘
│ pp: 0x1004─┼──┘ (p의 주소)
└────────────┘
```

**퀴즈**
> Q: `**pp`의 값은?
> - 0x1000
> - 0x1004
> - 10 ✓

### Lesson 10: 구조체와 포인터

**핵심 개념**
```
p->x == (*p).x
```

**코드**
```c
struct Point {
    int x;
    int y;
};

struct Point pt = {10, 20};
struct Point *p = &pt;
p->x = 100;
```

**시각화**
```
Stack:
┌────────────┐
│ pt.x: 100  │ 0x1000
│ pt.y: 20   │ 0x1004
│ p: 0x1000 ─┼──┘
└────────────┘
```

**퀴즈**
> Q: `p->y`와 `(*p).y`는?
> - 다르다
> - 같다 ✓

```
🤖 (자동 해설)
"*p = 20은 p가 가리키는 a의 값을 20으로 바꿉니다.
 많은 분들이 p 자체가 바뀐다고 착각해요."
```
