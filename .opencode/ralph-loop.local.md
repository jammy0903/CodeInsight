C언어 Playground 동작 테스트 및 모든 C 레슨 페이지의 시각화 데이터 검증. 다음 항목을 순차적으로 확인:
1. C Playground 엔드포인트 및 시뮬레이터 연동 확인
2. 간단한 C 코드로 Playground 실행 테스트 (포인터 포함)
3. 모든 C 레슨 JSON 파일 구조 검증 (points_to 필드, 메모리 상태)
4. CTransformer.ts가 레슨 데이터를 올바르게 변환하는지 확인
5. 각 레슨의 visualizationType과 시각화 데이터 일치성 검증
6. 발견된 문제점 리포트 작성 및 수정 제안
